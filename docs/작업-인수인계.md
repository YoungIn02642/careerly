## 남은 일 (우선순위 순)

### 1. 🔔 어드민 계정 — **미정, 계속 상기시켜 달라고 하심**
`backend/.env`의 `ADMIN_USERNAMES`가 비어 있음. 지금 영향:
- 커리어 인사이트 "공지로 올리기" 체크박스가 **안 보임** (관리자 전용)
- 운영방침 공지 글쓴이가 **첫 가입 회원** 이름으로 달려 있음
- 백오피스에 아무도 못 들어감

정하면 아이디 넣고 서버 재시작만 하면 됨.

### 2. 운영 DB 비밀번호 교체 (보안)
`.claude/settings.local.json`에 Railway 운영 MySQL 접속 문자열이 평문으로 있었음.
**깃 히스토리엔 안 올라감**(`git log -S`로 확인), `.gitignore`로 막아둠.
다만 이미 노출됐을 가능성은 확인 불가 → Railway에서 교체 권장.

### 3. 사람인 API 키 — **신청했으나 승인 대기**
승인되면 `backend/.env`의 `SARAMIN_ACCESS_KEY=` 뒤에 키만 붙이고 서버 재시작.
그때까지 채용공고 0건이라 **"담기 → 자소서 코치 인계" 흐름을 실제 데이터로 못 씀**
(렌더링·인계 로직은 주입한 가짜 공고로 검증 완료).

### 4. 워크넷 — **기업회원 전환 불가 확정**
개인회원 키라 목록 API가 막힘(`개인회원은 사용할 수 없는 OPEN-API입니다`).
코드(`backend/src/worknet-jobs.js`)는 **보조 경로로 남겨둠** — 사람인이 0건일 때만
시도하고 실패하면 사유를 화면에 표시. 지우려면 파일 1개 + 라우트 폴백 한 줄.

### 5. PR 만들기
베이스 `dev`. 저장소 규약: `feature/*` → PR → `dev` → PR → `main` (main 직접 푸시 금지).

### 6. 배포 시 필수
```bash
cd backend && node scripts/migrate-schema.js && node scripts/seed-notice.js
```
`insight_posts.is_notice` 컬럼이 추가됨.

**Railway 설정도 한 번 바꿔야 한다** — 앱 서비스 Settings 의 **Build Command 를
`npm run build`** 로. DART 기업 색인(6MB)을 깃에서 빼고 빌드에서 받도록 바꿨다.
`DART_API_KEY` 가 변수에 있어야 하고, 없으면 건너뛰고 배포는 그대로 된다
(기업분석 칸만 빔). 로컬은 클론 후 `npm run build` 한 번. 자세한 건 배포.md 1장.

| **타법인 출자현황** | 자회사·관계사. 업종코드 기반 경쟁사보다 정확 |

| 최대주주 현황 · 증자(감자) 현황 | 지배구조·자금조달 |

### 이미 확인된 한계 (다시 조사하지 말 것)
- **비상장사는 재무가 없다** — 캐논코리아처럼 DART 에 등록돼 있어도 사업보고서 제출
  의무가 없으면 `fnlttSinglAcnt`·`empSttus` 가 빈다. 개황(업종·설립·대표·본사·홈페이지)은
  나온다. 자세한 내용은 작업정리 16-8.
- **사업부문별 매출 비중은 오픈API에 없음.** DART 6개 그룹·공공데이터포털 어디에도 없고
  사업보고서 **본문**에만 글로 있음. 대신 **IR 홈페이지 링크**로 연결해 둠
  (카카오·LG에너지솔루션·네이버는 링크 있음, 삼성전자·현대차는 DART에 미등록).
- 채용공고 본문도 API로 못 받음 — 사람인·워크넷 둘 다 제목·조건만 줌.

## 알아둘 설계 판단 (되돌리지 말 것)

- **AI는 Groq 전용.** 프로바이더를 하나로 줄여 "안 켜져 있는 게 정상인 도구로 조용히
  떨어지는" 실패 모드를 없앰. 로컬 모델이 다시 필요해도 **기본값으로 두지 말 것**.
- **뉴스 필터는 규칙 기반, AI 안 씀.** 같은 회사를 두 번 검색했을 때 목록이 달라지면
  자소서 근거로 못 씀. 스포츠·연예 단어 "종류 수"를 세서 판단(KT→KT위즈 야구 기사 문제).
- **회사명 대조는 정확히 일치할 때만.** 부분 일치를 허용하면 '토스'에 '대한토스트'가 걸림.
  남의 회사 공고를 자기 것으로 알고 붙여넣는 쪽이 몇 건 놓치는 쪽보다 나쁨.
- **AI 초안은 대필이 아님.** 모르는 값은 `[팀원 수]` 처럼 대괄호로 비우고,
  한국어 아닌 글자가 섞이면 서버가 1회 재요청.
- **디자인은 Webflow 스펙 준수** (`frontend/css/jd-coach.css` 머리주석):
  주 버튼 근채색 #080808 / 유채색은 면 채우기만 / 모서리 4·8px / 굵기 상한 600 / 그라데이션 금지.
